# Core and CLI update — 2026-10-29

- Added N163 mapper-19 audio, NSF1/NSFe playback, `nsf-info`, `nsf-export` and
  `nsfe-export`. Track metadata and fractional durations survive conversion.
  See [music commands and limits](N163_NSF.md).
- Corrected N163 address auto-increment and digital mix gain; NSF playback uses
  an averaged voice mix to reduce multiplexing artifacts.
- Count completed frames consistently during instruction and frame stepping.
  A stopped CPU no longer fabricates a completed frame.
- Improved PPU status-read timing and VBlank write diagnostics, preserving the
  published mapped-CHR read buffer, CIRAM layouts, OAM DMA wrapping and FDS pitch.
- Decode load pseudocode from instruction bytes so immediates, memory reads,
  indexed addressing and indirect addressing are distinguishable. BRK reports
  an unresolved interrupt continuation instead of guessing a successor.
- Added side-effect-free Python debugger peeks through an isolated snapshot,
  traced stepping and observation helpers. Unsupported mapper restoration is
  reported explicitly. Existing snapshot floating-point precision is preserved.
- The public distribution remains core/CLI/integration APIs only.
